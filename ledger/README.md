# 가계부 봇 (lnledger)

텔레그램으로 가계부를 기록하는 봇입니다. `home` / `office` 두 개의 가계부로 나뉘며,
캄보디아 생활 특성상 **USD·KHR(리엘)·KRW 혼용**을 전제로 만들었습니다.

- 봇: `@hides_autocalc_bot` (번역봇 `lnteletranslate-tra` 와 별개 프로세스)
- 통신: **polling** — 웹훅/포트/인증서가 필요 없습니다.
- DB: `lunar-mariadb` 의 `lunar_ledger` 스키마

## 왜 별도 봇인가

번역봇은 그룹의 모든 대화를 읽어야 하지만, 가계부 봇은 그럴 필요가 없습니다.
이 봇은 **privacy mode(기본값)** 그대로 두므로 그룹에 초대해도 `/` 로 시작하는 명령만 보이고
두 사람의 대화 내용은 읽지 못합니다.

## 설치

```bash
cp config.example.json config.json   # 토큰·DB 비밀번호 입력
docker exec -i lunar-mariadb mariadb -uroot -p'<root_pw>' < schema.sql
docker compose up -d --build
```

## 명령어

| 명령 | 설명 | 예시 |
|---|---|---|
| `/buy` | 지출 | `/buy 120 pc 2대` |
| `/send` | 송금 | `/send 200 엄마` |
| `/add` | 수입 | `/add 1500 월급` |
| `/showcalc` | 이번달 집계표 | `/showcalc` `/showcalc office` `/showcalc 2026-07` |
| `/bal` | 이번달 잔액 | |
| `/list` | 최근 기록 | `/list 10` `/list office` |
| `/book` | 이 방의 기본 가계부 변경 | `/book office` |
| `/del` | 기록 취소(soft delete) | `/del 142` |
| `/whoami` | chat_id / user_id 확인 | |

한국어 별칭도 등록되어 있습니다: `/지출` `/송금` `/수입` `/잔액` `/목록`

### 금액 표기

| 입력 | 해석 |
|---|---|
| `120`, `$120`, `120usd`, `120불`, `120달러` | USD |
| `50000r`, `50000៛`, `៛50000`, `50000리엘`, `5만리엘` | KHR |
| `15000원`, `₩15000`, `1.5만원` | KRW |
| `1.2k`, `3천`, `5만` | 배수 단위 |
| `៥០០០០` | 크메르 숫자도 인식 |

통화 표기가 없으면 `defaultCurrency` 를 쓰되, **1,000 이상이면 리엘로 추정**하고
메시지에 ⚠️ 와 함께 정정 버튼을 붙입니다. 추정한 통화는 반드시 눈으로 확인하세요.

### 가계부 분리

메모 어디에든 `#home` / `#office` 를 넣으면 그 가계부로 기록됩니다.
(`#집` `#홈` `#사무실` `#회사` `#오피스` 도 인식)

```
/buy 120 프린터 토너 #office
```

태그가 없으면 그 채팅방의 기본 가계부(`/book` 으로 설정, 없으면 config 의 `chatBooks`)를 씁니다.
나중에 텔레그램 그룹을 home/office 두 개로 나누면 각 방에서 `/book` 을 한 번씩 눌러두면 됩니다.

### 날짜 지정

`@2026-08-10` 또는 `@08-10` 을 메모에 넣으면 그 날짜로 기록됩니다. 없으면 오늘.

## 평문(AI) 입력

**DM 에서** 명령어가 아닌 한국어 문장을 보내면 AI 가 해석해서 바로 실행합니다.
그룹에서는 동작하지 않습니다 — 두 사람의 일상 대화가 전부 AI 로 흘러가면 안 되기 때문입니다.

```
어제 시장에서 5만리엘 썼어      → 지출 ៛50,000 (어제 날짜로) 기록
사무실 프린터 토너 80달러 샀어   → office 가계부에 지출 $80 기록
월급 1500달러 들어왔어          → 수입 $1,500 기록
지금 입력분 삭제해줘            → 방금 기록 취소 + ↩️ 복구 버튼
142번 취소해줘                  → #142 취소
방금 지운거 되살려              → 복구
이번달 얼마 썼어?               → 집계표
잔액 알려줘 / 최근 내역 보여줘   → 잔액 / 목록
```

### 가계부 동작이 아니면 그냥 대화

명령도 아니고 가계부 조작도 아닌 말은 **일반 AI 대화로 받아줍니다.**

```
안녕! 오늘 기분이 별로네        → 대화
요즘 돈 관리 어떻게 해야 할까?   → 대화 (현재 가계부 현황을 알고 답함)
커피 4달러 썼어                → 대화 아님, 기록됨
이번달 얼마 썼어?              → 대화 아님, 집계표
```

- 대화 이력은 DB(`ledger_chat_history`)에 남아 **봇을 재시작해도 맥락이 이어집니다.**
  기본 10턴을 모델에 넘기고, 방마다 최근 40줄만 보관합니다.
- 이번달 book 별 수입/지출/잔액과 최근 기록 5건을 대화 모델에 함께 넘기므로
  *"이번달 좀 많이 쓴 것 같지 않아?"* 같은 질문에 실제 숫자를 보고 답합니다.
- 대화 답변은 **parse_mode 없이 평문**으로 보냅니다. 모델이 마크다운이나 `<`, `&` 를 뱉어도
  텔레그램 HTML 파서가 깨지지 않게 하기 위함입니다.
- 답변이 4,096자를 넘으면 문단 경계로 나눠 보냅니다.
- `/reset` 으로 대화 맥락을 지웁니다. `ai.chatEnabled: false` 로 끄면 예전처럼 안내문만 나갑니다.

### 공통

- Gemini(`gemini-2.5-flash`) 우선, 실패 시 OpenAI(`gpt-5.2`) 폴백.
- 최근 기록 5건을 문맥으로 넘기므로 *"아까 그 pc 취소해줘"* 같은 지시도 번호를 찾아냅니다.
- 삭제는 **soft delete(`status='void'`)** 라 복구 버튼으로 되살릴 수 있습니다.
- `recentMinutes`(기본 60분)보다 오래된 기록을 "방금 것"으로 지우면 경고를 붙입니다.
- AI 가 금액을 지어내지 않도록, 금액이 불명확하면 기록 대신 되묻습니다.

## 대화 자동 추출

번역봇이 남기는 `data/tra/covert-chats.json` 을 주기적으로(기본 180초) 읽어 거래를 추출합니다.
**번역봇은 전혀 건드리지 않습니다** — 이미 쌓고 있는 파일을 읽기 전용으로 마운트할 뿐이라
privacy mode 변경도, 가계부 봇을 그룹에 초대할 필요도 없습니다.

```
대화 전체 ─정규식─> 금액 단서 있는 것만 ─AI─> 진짜 거래만 ─> pending ─> DM 확인 버튼
  1,241건            122건 (9.8%)            19건 (1.5%)
```

**자동으로 저장하지 않습니다.** 9일치 실제 대화로 검증한 결과, 금액이 언급된 메시지 중
실제 거래는 **15% 뿐**이었습니다. 나머지 85%는 이런 것들입니다.

```
"400~500달러 정도야"        가격·시세 정보
"하고 싶으면 50달러 보내줘"   부탁·조건
"그 사람이 월 430달러예요"    시세
"한국에 가져갈 돈 250달러 있어"  보유 현황
"내가 준 돈에서 $100는 옷을 사요"  이미 준 돈의 사용처 지시
```

그래서 항상 DM 으로 확인을 받습니다.

```
💰 대화에서 발견 · 확신도 1.00
지출 −$25.00 "마트 지출"
“어젯밤에 제가 마트에서 25달러 썼어요.”
⚠️ #142 와 중복 가능 — $25.00 "마트"

[✅ 🏠 home 저장] [🏢 office 저장]
[❌ 무시]
```

### 알아둘 점

- **중복 경고** — 두 사람이 같은 거래를 각자 언급하면 한 번의 송금이 두 번 잡힙니다.
  같은 금액·통화가 24시간 내에 이미 있으면 경고를 붙입니다.
- **재처리 방지** — 처리한 메시지는 `ledger_source_seen` 에 남아 봇을 재시작해도 다시 묻지 않습니다.
- **첫 실행** — 파일에 남아 있던 과거 대화는 건너뜁니다 (`processBacklogOnStart: true` 로 바꾸면 처리).
- **AI 판정 실패 시** 해당 배치는 `seen` 처리하지 않아 다음 폴링에서 재시도합니다.
- 파일에 남는 대화는 최근 60건이므로, 폴링 주기를 너무 길게(3시간 이상) 잡으면 놓칠 수 있습니다.

## 환율

`config.json` 의 `fx` 는 **1 USD 당 각 통화 단위**입니다.

```json
"fx": { "USD": 1, "KHR": 4100, "KRW": 1380 }
```

기록 시점의 환율을 `rate_per_usd` 로 함께 저장하므로, 나중에 환율을 바꿔도
**과거 기록의 USD 환산액은 변하지 않습니다.**

## 접근 제어

- `ownerUserIds` — 여기 있는 user_id 만 기록/조회/버튼 조작이 가능합니다. 비어 있으면 전부 거부됩니다.
- `allowedChatIds` — 비우면 모든 방 허용, 채워두면 해당 방에서만 동작합니다.
- 모르는 명령(`/언어` 등 번역봇용)은 **조용히 무시**하므로 그룹에서 봇끼리 부딪히지 않습니다.

## 아직 안 한 것

- 대화 자동 추출(`source='auto'`, `status='pending'`) — 스키마와 콜백(`ok:<id>`)은 이미 준비되어 있고,
  번역봇 쪽에서 감지해 `pending` 으로 넣은 뒤 이 봇이 확인 버튼을 띄우는 구조로 붙일 수 있습니다.
- 웹 대시보드 — `covert-web` 에서 같은 DB 를 읽으면 됩니다.
